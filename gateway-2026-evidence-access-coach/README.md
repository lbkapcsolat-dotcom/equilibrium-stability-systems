# Evidence Access Coach — GatewayHacks 2026

A zero-spend, static Track 2 prototype for students who need to compare an assignment claim with one evidence excerpt.

## What it does
- Returns SUPPORTED, CONTRADICTED, or INSUFFICIENT for a bounded wording comparison.
- Shows a reason and a next evidence step.
- Runs entirely client-side with no account, API key, hosted model, or student-data collection.

## Run
Serve this folder with any static HTTP server and open `index.html`.

## Test
`node test.mjs`

## Claim ceiling
This is an educational evidence-comparison aid. It does not certify factual truth, scientific validity, source authority, or universal correctness.
