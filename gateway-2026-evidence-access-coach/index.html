How to read the result

SUPPORTED means the excerpt directly aligns with the claim wording. CONTRADICTED means the excerpt contains an opposing direction or explicit negation. INSUFFICIENT means the excerpt does not directly address enough of the claim.

Claim ceiling: this is an educational evidence-comparison aid. It does not certify truth, scientific validity, source authority, or universal correctness.

Static client-side prototype. No account, no paid API, no student data collection.
