# Publication Boundary

## Public by design

This repository may expose only material intentionally prepared for external inspection, such as:

- bounded demonstrations;
- reproducibility evidence;
- explicit claim limits;
- technical service descriptions;
- public research references.

## Non-public by default

Anything not intentionally prepared for external publication remains non-public.

That includes internal implementation details, internal operating structure, unpublished research, private data, credentials, configuration, and non-public operational state.

## Fail-closed publication rule

```text
UNCLEAR_PUBLICATION_STATUS -> DO_NOT_PUBLISH
```

Absence from this repository must not be interpreted as evidence about internal architecture, implementation, maturity, or capability.
